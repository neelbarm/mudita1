## The 80/20 (if you read nothing else)
1. **One identity per application** — Forward-Deployed AI Engineer. EMT/founder/Google are supporting evidence.
2. **Pre-empt the flight-risk question** ("I've made my choice — I build") in resume, LinkedIn, and every interview.
3. **5 outreach touches every weekday** + the daily quotas in file 6. Founders screen humans; ATS screens degrees — go where the humans are.
4. **No more certs. No new generic products.** Cased demos for target companies only.
